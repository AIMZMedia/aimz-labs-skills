# AIMZ LABS agent skill

An installable skill for agents using the AIMZ LABS MCP server. It covers media generation, Labs workflows, workspace nodes, and editable 3D blockout scenes and capture. The public skill contains guidance only; it does not contain credentials or install the MCP server.

## Install

In Codex, ask:

```text
$skill-installer로 https://github.com/AIMZMedia/aimz-labs-skills/tree/main/skills/aimz-labs 설치해줘
```

The skill is available on the next turn. In Claude Code, place [SKILL.md](skills/aimz-labs/SKILL.md) at `~/.claude/skills/aimz-labs/SKILL.md` for personal use, or `.claude/skills/aimz-labs/SKILL.md` in a project. See [Claude Code skill locations](https://code.claude.com/docs/en/skills). Existing installed copies must be updated separately when the repository changes.

Connect the MCP server separately using the [AIMZ LABS MCP setup guide](https://aimzlabs.com/docs/mcp). The [skill page](https://aimzlabs.com/docs/skills) also displays its instructions and installation guidance.

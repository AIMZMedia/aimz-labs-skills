# MiniMax H3: select the guide from actual inputs

Read the current official [reference-generation guide](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md) or [base guide](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md) before writing. The reference role and execution contract select the format; the model name alone does not.

For reference generation, use six ordered sections: subject_definitions, summary, retention_analysis, detailed_description, overall_soundscape, non_diegetic_music. Define each actual character, location or prop as a Subject and cite its source inside that definition. Identity/style reference pictures are not standalone definitions. Each retention row identifies the shots where that subject appears and its actual retention relation. Begin detailed_description with one or two English style sentences, then Shot 1 without a timestamp; use actual cut timestamps only for later shots. The main detailed_description normally contains 350–500 English words, subject to the official dialogue/editing exceptions. Do not replace that word range with an arbitrary total-character cap.

With no reference inputs, text-only uses T2VA, a first frame uses I2VA, and first plus last frames use FL2VA. Use the exact alignment wrapper and three core fields from the base guide. FL2VA normally follows one continuous shot between the actual frames. The official L2VA format describes a last frame alone, but the current Labs Atlas route rejects end_frame without start_frame; the guide does not add execution support. When Labs receives reference inputs alongside start/end images, its current adapter places those images before the other references in R2V; do not promise first/last-frame anchoring for that route.

AIMZ default: action Foley and environment sound only; non_diegetic_music is N/A. Explicitly prohibit background music, score, soundtrack, instruments, song and singing. Requested music is a separate track. Keep the user's requested actor/style and original dialogue or visible text; no generic story is imposed. Plan the ending in the generated clip.

Validate duration, resolution, frame grid and prompt limits against the **actual execution route**. A hosted limit does not establish a local graph limit. These are authoring instructions: direct user prompts and generation inputs are not rewritten. Inspect the real output and do not claim listening without playback.
